02 / TWO GOGAR CASES

두 증명 모두
질문으로 따라가기

아래 대화는 발표할 때 보여 줄 수 있는 축약본입니다. 각 카드에서 질문 → 학생의 추론 → 수식의 변화가 한 묶음으로 움직입니다.

CASE AQUADRATIC FORMULA

근의 공식 만들기

출발: ax2 + bx + c = 0, a ≠ 0

Q1GoGAR 질문

x2의 계수를 1로 만들려면 무엇을 할까요?

학생의 추론 a ≠ 0이므로 양변을 a로 나눌 수 있습니다. x를 다루기 쉬운 형태로 바꾸는 첫 단계입니다.

x2 + bax + ca = 0
Q2GoGAR 질문

x가 있는 식을 하나의 제곱으로 만들 수 있을까요?

학생의 추론 x의 계수 b/a의 절반을 제곱한 값을 양변에 더하면 완전제곱이 됩니다.

(x + b2a)2 = b2 − 4ac4a2
Q3GoGAR 질문

제곱 형태가 되었으니 x를 어떻게 꺼낼까요?

학생의 추론 양변의 제곱근을 취합니다. 제곱근에는 양의 경우와 음의 경우가 모두 있으므로 ±가 필요합니다.

x + b2a = ± √(b2 − 4ac)2a
GO GAR RESULTx = −b ± √(b2 − 4ac)2a
CASE BARITHMETIC–GEOMETRIC MEAN

산술·기하평균 부등식

목표: a, b ≥ 0일 때 (a + b) / 2 ≥ √ab

Q1GoGAR 질문

우리가 비교하려는 두 값은 무엇인가요?

학생의 추론 두 수의 합을 2로 나눈 산술평균과, 두 수의 곱의 제곱근인 기하평균입니다.

a + b2 ≥ √ab
Q2GoGAR 질문

항상 0 이상이라고 확실히 말할 수 있는 식은 무엇일까요?

학생의 추론 어떤 수를 제곱한 값은 항상 0 이상입니다. √a와 √b의 차이를 제곱해 봅니다.

(√a − √b)2 ≥ 0
Q3GoGAR 질문

제곱을 전개하면 목표에 가까워지나요?

학생의 추론 전개하면 a − 2√ab + b ≥ 0, 즉 a + b ≥ 2√ab가 됩니다.

a + b ≥ 2√ab
Q4GoGAR 질문

양변을 2로 나누면 어떤 결론인가요? 언제 같아질까요?

학생의 추론 (a+b)/2 ≥ √ab이고, (√a−√b)2=0인 a=b에서 등호가 성립합니다.

∴ a + b2 ≥ √ab, equality ⇔ a = b
GO GAR RESULTa + b2 ≥ √ab등호 조건: a = b
