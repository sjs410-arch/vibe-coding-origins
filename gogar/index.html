01 / WHAT IS GOGAR?

GoGAR,
이유를 주고 묻는 게임

Game of Giving and Asking for Reasons

GoGAR는 서로의 주장에 이유를 제시하고 요구하면서, 무엇을 정당하게 말할 수 있는지 점검하는 대화의 실천입니다. ‘게임’은 주장·질문·정당화에 규칙이 있다는 뜻입니다. 개념을 이해한다는 것은 그 말의 근거와 결과를 알고, 다른 주장과의 충돌도 알아차리는 일입니다. [2]

ORIGIN / CONCEPT / MATHEMATICS

누가 발전시킨
개념인가요?

이 개념의 철학적 뿌리는 윌프리드 셀라스(Wilfrid Sellars)에게 있으며, 로버트 브랜덤(Robert Brandom)이 언어와 추론에 관한 철학에서 체계적으로 발전시켰습니다. [1][2]

PHILOSOPHICAL ROOTS

셀라스 → 브랜덤

셀라스는 앎을 자신이 말한 것을 정당화할 수 있는 ‘이유의 공간’과 연결했습니다. 브랜덤은 Making It Explicit(1994)에서 주장에 대한 책임과 정당화 자격을 주고받는 구조를 상세히 전개했습니다.

INFERENTIALISM / 추론주의

안다는 것은, 연결할 수 있다는 것

개념의 의미를 그 개념이 다른 주장들과 맺는 추론 관계에서 이해합니다. 수학에서는 “어떤 조건에서 이 식을 쓸 수 있는가?”와 “이 식으로부터 무엇을 얻는가?”를 함께 설명하는 데 적용할 수 있습니다. [3]

A SMALL MATHEMATICAL EXAMPLE

“6은 짝수다.”
이 한 문장을 이해한다면?

아래는 개념을 설명하기 위해 구성한 수학 대화입니다. 주장의 근거와 결과를 잇고, 잘못된 근거가 나오면 함께 고칩니다.

6 = 2 × 3

짝수의 정의: 어떤 정수 k에 대해 2k로 나타낼 수 있는 정수

  1. 주장

    학생 “6은 짝수입니다.”이 주장을 하고, 필요한 경우 이유를 설명할 책임을 집니다.

  2. 근거 묻기

    교사·친구 “왜 그렇게 말할 수 있나요?”학생: “6 = 2 × 3이고, 3은 정수이기 때문입니다.”

  3. 결과 묻기

    교사·친구 “그러면 2로 나누었을 때 나머지는?”학생: “0입니다. 2로 나누어떨어집니다.”

  4. 근거 점검

    교사·친구 “‘3의 배수라서 짝수’라고 해도 될까요?”학생: “9는 3의 배수지만 홀수입니다. 그 이유만으로는 부족합니다.”

  5. 정당화

    함께 확인 “6이 정수의 2배라는 점이 짝수라는 주장의 근거입니다.”주장과 적절한 근거의 연결이 드러나면, 그 주장을 정당하게 할 자격이 뒷받침됩니다.

UPSTREAM / 상류

이 주장의 근거는?

DOWNSTREAM / 하류

무엇이 따라오는가?

INCOMPATIBILITY / 양립 불가능성

무엇과 함께 성립할 수 없는가?

같은 의미에서 “6은 홀수”라는 주장을 함께 정당화할 수 없습니다.

이 홈페이지의 수업 설계 사람 사이의 이유 주고받기를 바탕으로, AI와 바이브코딩을 활용해 학생이 근거를 쓰고 질문을 따라갈 수 있는 화면으로 응용했습니다. 학생이 막힌 곳이 조건인지, 식의 변형인지, 결론인지 드러내는 것을 목표로 합니다.

CASE AQUADRATIC FORMULA

근의 공식 만들기

출발: ax2 + bx + c = 0, a ≠ 0

Q1GoGAR 질문

x2의 계수를 1로 만들려면 무엇을 할까요?

학생의 추론 a ≠ 0이므로 양변을 a로 나눌 수 있습니다. x를 다루기 쉬운 형태로 바꾸는 첫 단계입니다.

x2 + bax + ca = 0
Q2GoGAR 질문

x가 있는 식을 하나의 제곱으로 만들 수 있을까요?

학생의 추론 x의 계수 b/a의 절반을 제곱한 값을 양변에 더하면 완전제곱이 됩니다.

(x + b2a)2 = b2 − 4ac4a2
Q3GoGAR 질문

제곱 형태가 되었으니 x를 어떻게 꺼낼까요?

학생의 추론 양변의 제곱근을 취합니다. 제곱근에는 양의 경우와 음의 경우가 모두 있으므로 ±가 필요합니다.

x + b2a = ± √(b2 − 4ac)2a
GO GAR RESULTx = −b ± √(b2 − 4ac)2a

CASE BINFINITE GEOMETRIC SERIES

무한등비급수

출발: Sn = a + ar + ⋯ + arn−1. a ≠ 0인 실수 등비급수의 수렴 조건을 확인합니다.

Q1 / 상류GoGAR 질문

끝까지 더할 수 없는 무한합을 어떻게 정의할까요?

학생의 추론 유한한 개수의 항을 더한 부분합 Sn을 먼저 만듭니다. 이 부분합의 유한한 극한이 존재할 때 그 극한을 급수의 합이라고 정의합니다.

S = limn→∞ Sn
Q2 / 하류GoGAR 질문

Sn에서 rSn을 빼면 무엇이 남나요?

학생의 추론 가운데 항이 소거되어 a − arn만 남습니다. r ≠ 1이면 1 − r로 나눌 수 있고, r = 1이면 Sn = na입니다.

Sn = a(1 − rn)1 − r (r ≠ 1)
Q3 / 조건GoGAR 질문

rn이 0으로 가려면 공비는 어느 범위여야 할까요?

학생의 추론 |r| < 1이어야 합니다. 음수인 공비도 절댓값이 1보다 작으면 0으로 갑니다. a ≠ 0일 때 r = 1은 발산하고, r = −1은 부분합이 진동합니다.

|r| < 1 ⇒ rn → 0 ⇒ S = a1 − r
Q4 / 양립 불가GoGAR 질문

1 + 2 + 4 + ⋯ = −1이라는 계산은 왜 잘못됐나요?

학생의 추론 부분합이 발산하는데도 무한합을 유한한 수 S로 놓고 뺄셈한 것이 오류입니다. 반면 0.999⋯은 a = 0.9, r = 0.1이므로 공식을 적용해 1을 얻을 수 있습니다.

0.999⋯ = 0.91 − 0.1 = 1
GO GAR RESULTa + ar + ar2 + ⋯ = a1 − ra ≠ 0인 실수 등비급수의 수렴 조건: |r| < 1

CASE CFUNDAMENTAL THEOREM OF CALCULUS

미적분학의 기본정리

조건: f는 [a, b]에서 연속, F(x) = ∫ax f(t) dt. 내부점 a < x < b에서 F′(x) = f(x)를 설명합니다.

Q1 / 상류GoGAR 질문

적분의 위끝을 x로 바꾸면 무엇이 달라질까요?

학생의 추론 F(x)는 a부터 x까지의 누적량을 알려 주는 함수입니다. 예를 들어 f(t) = 2, a = 0이면 F(x) = 2x이고, 미분하면 원래 함수값 2가 나옵니다.

F(x) = ∫0x 2 dt = 2x
Q2 / 하류GoGAR 질문

F(x+h) − F(x)를 h로 나누면 무엇을 뜻하나요?

학생의 추론 증가량은 x와 x+h 사이의 정적분입니다. 차분몫은 그 구간의 평균 함수값입니다. h가 0으로 갈 때 연속성에 의해 f(x)로 가까워집니다.

limh→0 F(x+h) − F(x)h = f(x)
Q3 / 양립 불가GoGAR 질문

∫1x t² dt를 미분하면 x² − 1인가요?

학생의 추론 아닙니다. 적분값 x³/3 − 1/3에서 −1/3은 상수이므로 미분하면 0입니다. 아래끝을 바꿔도 상수 차이만 생기므로 미분 결과는 x²입니다.

(x3/3 − 1/3)′ = x2
Q4 / 정당화GoGAR 질문

왜 정적분을 G(b) − G(a)로 계산할 수 있나요?

학생의 추론 G′ = f이면 G와 F의 차이는 상수입니다. F(a) = 0이므로 F(b) = G(b) − G(a). 미분과 적분의 연결이 이 계산을 정당화합니다.

∫01 x2 dx = [x3/3]01 = 1/3
GO GAR RESULTF′(x) = f(x)
∫ab f(x) dx = G(b) − G(a)f는 연속, G′ = f. 정적분은 부호를 가진 누적량으로 생각합니다.
