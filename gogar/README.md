# GoGAR Proof Lab

근의 공식과 산술·기하평균 부등식이라는 두 수학 주제를 모두 GoGAR식 질문·응답·피드백으로 설명하는 발표용 GitHub Pages 자료입니다.

- `index.html`: GoGAR의 의미, 두 증명 사례, 바이브코딩 제작 과정을 소개하는 발표용 홈페이지
- `lesson.html`: 근의 공식 GoGAR 대화형 수업
- `amgm-lesson.html`: 산술·기하평균 부등식 GoGAR 대화형 수업
- `styles.css`, `script.js`: 홈페이지의 화면 구성과 상호작용

## 발표 흐름

1. 어려운 증명을 질문 단위로 나누는 GoGAR식 접근을 소개합니다.
2. 근의 공식에서 완전제곱을 만드는 과정을 질문으로 따라갑니다.
3. 산술·기하평균 부등식에서 제곱의 비음성, 전개, 등호 조건을 질문으로 따라갑니다.
4. 서로 다른 수학 주제에 같은 질문 구조를 적용할 수 있음을 비교합니다.
5. 자연어 요구가 HTML·CSS·JavaScript 학습 화면으로 바뀌는 바이브코딩 과정을 소개합니다.
