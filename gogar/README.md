# GoGAR Proof Lab

근의 공식, 무한등비급수, 미적분학의 기본정리라는 세 수학 주제를 GoGAR식 질문·응답·피드백으로 설명하는 발표용 GitHub Pages 자료입니다.

- `index.html`: GoGAR의 의미와 출처, 세 증명 사례, 바이브코딩 제작 과정을 소개하는 발표용 홈페이지
- `lesson.html`: 근의 공식 GoGAR 대화형 수업
- `series-lesson.html`: 첨부된 무한등비급수 GoGAR 수업 자료에 홈페이지 이동 링크를 더한 페이지
- `ftc-lesson.html`: 첨부된 미적분 기본정리 GoGAR 수업 자료에 홈페이지 이동 링크를 더한 페이지
- `styles.css`, `script.js`: 홈페이지의 화면 구성과 상호작용

## 발표 흐름

1. 어려운 증명을 질문 단위로 나누는 GoGAR식 접근을 소개합니다.
2. 근의 공식에서 완전제곱을 만드는 과정을 질문으로 따라갑니다.
3. 무한등비급수에서 부분합, 수렴 조건, 잘못된 무한합 계산을 질문으로 점검합니다.
4. 미적분학의 기본정리에서 누적량과 변화율의 관계, 연속성, 정적분 계산의 정당화를 연결합니다.
5. 세 주제에 공통되는 상류·하류·양립 불가능성·정당화 자격을 비교합니다.
6. 자연어 요구가 HTML·CSS·JavaScript 학습 화면으로 바뀌는 바이브코딩 과정을 소개합니다.

각 체험은 5단계이며 미리 준비된 질문, 키워드 기반 피드백, 힌트로 동작합니다. 새 두 수업의 학습 질문과 피드백은 제공된 HTML 자료를 사용합니다.
