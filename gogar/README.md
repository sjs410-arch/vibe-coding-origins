# GoGAR Reasoning Lab

바이브코딩으로 수학적 추론과 정당화를 학습하는 발표용 GitHub Pages 자료입니다. 근의 공식, 무한등비급수, 미적분학의 기본정리라는 각각 독립적인 세 주제에서 조건·근거·결과를 설명하는 연습을 합니다.

- `index.html`: GoGAR의 의미와 출처, 세 추론·정당화 학습 사례, 바이브코딩 제작 과정을 소개하는 발표용 홈페이지
- `quadratic-lesson.html`: 근의 공식 GoGAR 대화형 추론·정당화 연습
- `lesson.html`: 같은 근의 공식 앱의 기존 주소 호환본
- `series-lesson.html`: 첨부된 무한등비급수 GoGAR 수업 자료에 홈페이지 이동 링크를 더한 페이지
- `ftc-lesson.html`: 첨부된 미적분 기본정리 GoGAR 수업 자료에 홈페이지 이동 링크를 더한 페이지
- `styles.css`, `script.js`: 홈페이지의 화면 구성과 상호작용

## 발표 흐름

1. 셀라스의 앎과 이유의 공간 → 브랜덤의 의미·추론주의 → 수학교육 연구의 GoGAR 활용을 구분해 소개합니다. 표현의 최초 조어자는 단정하지 않으며 설명용 슬로건과 직접 인용을 구분합니다.
2. 근의 공식에서 완전제곱을 만드는 과정을 질문으로 따라갑니다.
3. 무한등비급수에서 부분합, 수렴 조건, 잘못된 무한합 계산을 질문으로 점검합니다.
4. 미적분학의 기본정리에서 누적량과 변화율의 관계, 연속성, 정적분 계산의 정당화를 연결합니다.
5. 더밋의 적용의 조건·결과를 계승한 브랜덤의 상류·하류를 먼저 정의합니다. 무한등비급수의 합 공식을 중심 주장으로 삼아 근거·조건과 결과·책임을 설명하고, 별도의 양립 불가능성 점검 및 세 주제 비교로 확장합니다.
6. 자연어 요구가 HTML·CSS·JavaScript 학습 화면으로 바뀌는 바이브코딩 과정을 소개합니다.

각 체험은 5단계이며 미리 준비된 질문, 키워드 기반 피드백, 힌트로 동작합니다. 한 질문 안의 분할 답변 누적과 단계형 힌트(작은 질문, 빈칸 채우기, 정답 공개)를 지원합니다. 제공된 앱의 학습 흐름과 판정 규칙은 유지하고, 소개와 완료 안내를 추론·정당화 연습에 맞게 수정했습니다.

## 자료의 범위

증명과 추론·정당화는 서로 배타적인 분류가 아닙니다. 증명은 추론을 통해 주장을 정당화하는 논증입니다. 이 자료는 근의 공식의 유도, 급수의 수렴 조건과 합의 증명, 미적분학의 기본정리의 핵심 증명을 따라가며 각 추론을 정당화하는 연습을 다룹니다. 미적분학 사례에는 h < 0에서도 차분몫이 구간의 평균 함수값이 된다는 안내를 더해 내부점의 양쪽 극한을 설명합니다. 응답 통과가 학생이 작성한 증명 전체의 타당성을 보장하지는 않습니다. 근거와 조건 설명은 교사·친구와 함께 검토해야 하며, 학습 효과는 별도 검증이 필요합니다.
