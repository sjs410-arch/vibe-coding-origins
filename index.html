02LINEAGE

시간의 계보

한 단어 뒤에
쌓여 있던 시간

각 시기를 눌러 그 시기의 질문과 바이브코딩으로 이어지는 연결고리를 확인해 보세요.

1950s 자동 프로그래밍 +

사람이 고수준의 설명을 쓰면 컴퓨터가 실행 가능한 프로그램으로 바꾸어 주기를 바라는 연구가 시작되었습니다.

THE DREAM BEGINS
1960s–70s 자연어 프로그래밍 +

영어와 자연어를 프로그래밍 언어로 사용할 수 있는지 탐구했습니다. SHRDLU와 LINGOL은 대화로 컴퓨터를 조작한다는 발상을 넓혔습니다.

MEANING OVER SYNTAX
1980s–2010s 최종 사용자 프로그래밍 +

예제로 하는 프로그래밍, 프로그래밍 시연, 자연스러운 프로그래밍, 로우코드는 비전문가도 자신의 필요에 맞는 프로그램을 만들 수 있게 하려 했습니다.

END-USER POWER
2021–24 LLM과 대화형 코딩 +

Codex와 Copilot을 시작으로 자연어 설명에서 코드가 생성되기 시작했습니다. 코드 편집기와 챗봇이 결합되며 생성·설명·수정·탐색이 하나의 대화가 되었습니다.

CONVERSATIONAL TOOLS
2025.02.02 ‘vibe coding’이라는 이름 +

카파시는 자연어·음성으로 AI에게 지시하고, 생성된 코드를 자세히 읽기보다 실행 결과와 오류를 다시 AI에게 전달하는 작업 방식을 설명했습니다.

“There’s a new kind of coding I call ‘vibe coding’.”
THE NAME ARRIVES
2025–26 문화적 표현으로 확장 +

바이브코딩은 좁은 실천 개념에서 자연어로 AI에게 코드를 시키는 개발 전반을 가리키는 대중적 표현으로 넓어졌습니다. 동시에 인간의 역할은 명세·감독·검증으로 이동했습니다.
